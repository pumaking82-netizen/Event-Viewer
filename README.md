# PC Crash Monitor v1.1

This version fixes GPU telemetry compatibility by removing NVIDIA sensor queries that are not supported on every GeForce card/driver.

For motherboard voltage rails, CPU package temperature/power, AIO pump, and motherboard fan sensors, run LibreHardwareMonitor as Administrator while PC Crash Monitor is running.

After a crash, send the newest session folder from `Documents\PC_Crash_Monitor`.
